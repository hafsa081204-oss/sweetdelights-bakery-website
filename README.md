# 🧁 Sweet Delights Bakery Website

A responsive bakery website for Sweet Delights, a Sri Lankan bakery in Colombo. Visitors can browse the menu, add items to a cart, read the bakery's story, and send a message or custom order request.

## Features

- Menu with category filters (Srilankan Savouries, Sweets & Pastries, Cakes, Specials)
- Add to Cart button on every item, with a live cart counter
- "Our Story" section with customer reviews
- Contact form for messages and custom order requests
- Opening hours, address, phone, and email details

## Built With

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the `sweetdelights` folder.
3. Double-click `index.html` to open the website in your browser.
